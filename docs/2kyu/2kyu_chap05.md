# 05. 輸配送システムの設計と最適化

## 「どう運ぶか」から「どう組み合わせるか」へ

3級では、輸送と配送の違い、輸送モードの選び方、共同配送の考え方を学びました。2級では、これらを組み合わせて「輸配送のネットワーク全体をどう設計し、最適化するか」という、より実践的な視点を学びます。

## 輸配送計画の最適化問題（VRPの考え方）

複数の届け先に荷物を配送する際、「どのトラックが」「どの順番で」「どのルートを回るか」によって、必要な台数や走行距離は大きく変わります。この「複数の届け先を、限られた車両で効率よく回るには、どう組み合わせるべきか」という問題を、輸送業界では「配送計画問題（VRP：Vehicle Routing Problem）」と呼びます。

2級の段階では、複雑な数式を解けるようになる必要はありません。重要なのは、次のような要素が輸配送計画の効率に影響するという考え方を理解することです。

- 届け先の位置関係と、まとめて回れる順序
- 車両1台あたりの積載可能量と、荷物の総量
- 各届け先で指定された時間帯（配送時間指定）
- ドライバーの労働時間・拘束時間の制約

近年では、これらの条件を踏まえた最適な配送ルートを、コンピュータで自動計算する「配送計画システム」の導入が進んでいます。属人的な「ベテランドライバーの勘」に頼っていた配送ルート設計を、データにもとづいて最適化することが可能になっています。

## モーダルシフトを経営判断として設計する

3級では、モーダルシフトが労働力不足・環境負荷の両面で必要とされる背景を学びました。2級では、これを「どう実行に移すか」という設計の視点で捉え直します。

モーダルシフトを検討する際に評価すべきポイントは、次の通りです。

| 評価ポイント | 内容 |
|---|---|
| 輸送距離 | 長距離であるほど、鉄道・船舶へのシフトの効果が大きい |
| 荷姿・ロットサイズ | ある程度まとまった量を、定期的に輸送できるかどうか |
| リードタイムの許容度 | 鉄道・船舶は輸送日数がかかるため、納期に余裕がある貨物に向く |
| 末端区間の輸送手段 | 鉄道駅・港湾から届け先までの、トラックによる集荷・配達手段の確保 |

モーダルシフトは「切り替えれば必ずコストが下がる」わけではなく、末端区間のトラック輸送や、輸送日数増加によるリードタイムの延びといった、新たなコスト・制約も発生します。全体としてのコストとサービス水準のバランスを見て判断する必要があります。

## 共同輸配送の設計パターン

3級で学んだ共同配送を、2級では実行の仕組みとして捉えます。共同輸配送には、主に次のようなパターンがあります。

- **水平的共同化**：同業他社同士が、同じエリア・同じ届け先への配送を共同で行う
- **垂直的共同化**：メーカー・卸・小売など、サプライチェーン上の異なる立場の企業が、輸配送を共同で行う
- **プラットフォーム型**：物流事業者が構築した共同配送のプラットフォームに、複数の荷主が参加する

どのパターンでも、共同化のためには、荷姿・伝票様式・情報システムなど、参加企業間でのルールの標準化が前提条件になります。標準化ができていないと、共同化によるメリットよりも、調整の手間の方が大きくなってしまうことがあります。

## 実務でどう使われているか

ある地域の中小食品メーカー数社が、それぞれ個別に、同じ小売チェーンへの配送を行っていました。各社の積載率は低く、非効率な状態が続いていました。

これらの企業が水平的共同化に取り組み、共同の配送センターと配送計画システムを導入した結果、車両1台あたりの積載率が向上し、走行台数を大幅に削減できました。導入にあたっては、各社の伝票様式やパレット規格を統一するという地道な準備が必要でしたが、それを乗り越えたことで、継続的なコスト削減につながっています。

## 3行まとめ

1. 輸配送計画の最適化（VRP）は、届け先の位置・積載量・時間指定などを踏まえてルートを設計する考え方である。
2. モーダルシフトは、輸送距離・荷姿・リードタイムの許容度・末端区間の輸送手段を総合的に評価して判断する。
3. 共同輸配送を機能させるには、荷姿・伝票・情報システムなどの標準化が前提条件になる。

## 一問一答

**Q1.** 配送計画問題（VRP）が扱う課題として最も適切なものはどれか。
①商品の価格設定　②限られた車両で複数の届け先を効率よく回るルート・組み合わせの設計　③倉庫の立地選定

> 解答：②

**Q2.** モーダルシフトの評価ポイントとして適切でないものはどれか。
①輸送距離　②リードタイムの許容度　③商品のパッケージデザイン

> 解答：③

**Q3.** 次の記述の正誤を答えよ。「モーダルシフトは、末端区間の輸送手段を考慮しなくても常にコスト削減につながる」

> 解答：誤。末端区間のトラック輸送やリードタイム増加など、新たなコスト・制約も考慮する必要がある。

**Q4.** 同業他社同士が同じエリアへの配送を共同で行う共同化のパターンはどれか。
①水平的共同化　②垂直的共同化　③プラットフォーム型のみ

> 解答：①
