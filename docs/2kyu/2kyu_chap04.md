# 04. 包装・荷役・保管の応用管理

## 「バラバラに運ぶ」から「まとめて運ぶ」へ

3級では、包装・荷役・保管をそれぞれ独立した機能として学びました。2級では、これらを一体として最適化する「ユニットロード化」という考え方と、保管を自動化する「自動倉庫」の導入判断を学びます。

## ユニットロード化とは何か

ユニットロード化とは、複数の商品をパレットやコンテナといった一定の単位（ユニット）にまとめ、そのまま輸送・保管・荷役を行う考え方です。商品を1つずつ扱うのではなく、まとまった単位のまま扱うことで、次のような効果が得られます。

- 荷役の回数そのものが減る（3級で学んだ荷役の5大原則の「数量減少の原則」に対応）
- 積み降ろしがフォークリフト等で機械化でき、荷役時間が短縮される
- パレット単位で保管することで、在庫の数量管理がしやすくなる

一方で、ユニットロード化には、パレットやコンテナの規格を取引先・輸送手段間で統一する必要があるという課題もあります。規格が統一されていないと、途中で積み替えが必要になり、かえって荷役の手間が増えてしまいます。

## パレートプールという仕組み

日本では、企業ごとにパレットを所有すると、輸送の行き帰りで空のパレットを回収する手間（片荷輸送の非効率）が発生しやすいという課題があります。これを解決する仕組みが「パレットプールシステム」です。

パレットプールとは、業界全体で規格化された共有パレットを、専門の管理会社を通じてレンタルし合う仕組みです。荷主・物流事業者は、自社でパレットを保有・回収する必要がなくなり、業界全体でのパレット規格の統一・循環利用が進みます。

## 自動倉庫（AS/RS）導入の判断基準

自動倉庫（AS/RS：Automated Storage and Retrieval System）は、ラックへの入出庫をコンピュータ制御で自動化する設備です。3級では概要を学びましたが、2級ではその「導入判断」の視点が問われます。

自動倉庫の導入を検討する際に評価すべき主な観点は、次の通りです。

| 観点 | 内容 |
|---|---|
| 投資回収期間 | 導入コストに対して、人件費削減・スペース効率化でどれだけ回収できるか |
| 取扱商品の特性 | 形状・サイズが均一な商品ほど自動化しやすい。多品種少量・不定形の商品は不向きな場合がある |
| 需要変動への対応力 | 自動倉庫は稼働の柔軟性が低い場合があり、急激な物量増減への対応力を事前に検討する必要がある |
| 労働力確保の見通し | その地域で今後も人手を確保し続けられるかどうかの見通し |

自動倉庫は「導入すれば必ず効率化できる」わけではなく、扱う商品や物量の特性によっては、人手による作業のほうが柔軟でコスト効率が良い場合もあります。2級では、このような「自動化すべきかどうか」を状況に応じて判断する視点が重視されます。

## 実務でどう使われているか

ある食品卸売業者では、取引先ごとに異なる規格のパレットを使用していたため、荷積みのたびに商品を積み替える手間が発生していました。業界標準のパレットプールに加入し、規格を統一したことで、積み替え作業がなくなり、荷役時間を大幅に短縮できました。

一方、別の物流センターでは、季節や商戦によって取扱商品と物量が大きく変動するため、自動倉庫の導入を見送り、柔軟に人員を増減できる人手中心のオペレーションを維持するという判断を下しました。これは、自社の商品特性・物量変動を踏まえた合理的な経営判断の一例です。

## 3行まとめ

1. ユニットロード化は、商品をパレット等の単位でまとめて扱うことで、荷役の回数と時間を減らす考え方である。
2. パレットプールは、業界で規格化されたパレットを共有し、片荷輸送の非効率を解消する仕組みである。
3. 自動倉庫の導入は、投資回収期間・商品特性・需要変動への対応力を踏まえて判断すべきであり、常に最適とは限らない。

## 一問一答

**Q1.** ユニットロード化の説明として正しいものはどれか。
①商品を1つずつ手作業で運ぶこと　②商品をパレット等の単位にまとめて輸送・保管・荷役すること　③商品の包装を簡素化すること

> 解答：②

**Q2.** パレットプールシステムが解決しようとする課題はどれか。
①パレットの規格がバラバラで積み替えが発生する非効率　②トラックの速度制限　③在庫の陳腐化

> 解答：①

**Q3.** 次の記述の正誤を答えよ。「自動倉庫は、多品種少量で不定形な商品を扱う現場に、常に最も適した設備である」

> 解答：誤。自動倉庫は形状・サイズが均一な商品に向いており、多品種少量・不定形な商品には不向きな場合がある。

**Q4.** 自動倉庫の導入判断で検討すべき観点に含まれないものはどれか。
①投資回収期間　②取扱商品の特性　③自社のブランドカラー

> 解答：③
