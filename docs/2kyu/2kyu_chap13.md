# 13. 環境・CSR・法規制対応の高度化

## 「守るべきルール」から「選ばれる理由」へ

3級では、省エネ法やホワイト物流など、物流に関する環境・労働のルールを学びました。2級では、これらへの対応が単なる「規制順守」にとどまらず、企業が取引先や社会から選ばれるための経営戦略になっているという視点を学びます。

## カーボンニュートラルと物流の関係

「カーボンニュートラル」とは、CO2をはじめとする温室効果ガスの排出量と吸収量を均衡させ、実質的な排出量をゼロにするという考え方です。物流は、トラック・船舶・航空機の燃料消費など、多くのCO2を排出する活動であるため、カーボンニュートラルの実現において重要な領域とされています。

物流分野でのCO2削減に向けた代表的な取り組みには、次のようなものがあります。

| 取り組み | 内容 |
|---|---|
| モーダルシフト | CO2排出量の少ない鉄道・船舶への転換（3級・2級で既出） |
| 輸送効率化 | 積載率向上、共同配送によるトラック台数の削減 |
| 燃料・車両の転換 | EVトラック、水素トラックなど、次世代車両の導入 |
| 物流拠点の省エネ化 | 太陽光発電、高効率な空調・照明の導入 |

これらの取り組みは、単独では効果が限定的であることが多く、複数の施策を組み合わせて初めて、大きな削減効果が期待できます。

## サプライチェーン全体で問われる環境対応（スコープ3）

近年、企業の環境対応において重要になっているのが「スコープ3」という考え方です。企業のCO2排出量は、次の3つの区分（スコープ）で整理されます。

- **スコープ1**：自社が直接排出するCO2（自社の工場の燃焼など）
- **スコープ2**：自社が購入した電力・熱の使用に伴うCO2
- **スコープ3**：自社の活動に関連する、サプライチェーン上の他社の排出（仕入先の生産、委託輸送など）

物流を外部委託している場合、その輸送で発生するCO2は、荷主企業にとって「スコープ3」に該当します。つまり、荷主企業は自社が直接トラックを保有していなくても、委託先の物流事業者の環境対応まで含めて、自社の環境責任として問われる時代になっているということです。これが、荷主企業が物流事業者の環境対応に強い関心を持つ理由になっています。

## CSRとしての物流：ホワイト物流のその先へ

3級で学んだ「ホワイト物流」は、主に労働環境改善を目的とした取り組みでしたが、2級ではこれをCSR（企業の社会的責任）・ESG経営という、より広い経営文脈の中に位置づけて理解します。

- **社会（S）の観点**：ドライバーの労働環境改善、荷待ち時間の削減
- **環境（E）の観点**：モーダルシフト、CO2削減の取り組み
- **ガバナンス（G）の観点**：物流委託先の労務・環境コンプライアンスの管理

投資家や取引先が企業を評価する際に、こうしたESGの取り組みを重視する傾向が強まっており、物流における環境・労働対応は、単なるコストや規制順守ではなく、企業価値そのものに関わる経営課題として扱われるようになっています。

## 実務でどう使われているか

ある大手小売企業では、自社の直接排出（スコープ1・2）の削減は進んでいたものの、委託している輸送事業者のCO2排出（スコープ3）については把握できていませんでした。

投資家からのESG評価の要請を受け、主要な物流委託先に対してCO2排出量の報告を求め、モーダルシフトや低燃費車両の導入状況を取引継続の評価項目に加えました。これにより、荷主企業が自社の直接活動だけでなく、委託先も含めたサプライチェーン全体で環境対応を推進する体制が構築されました。

## 3行まとめ

1. カーボンニュートラルに向け、モーダルシフト・輸送効率化・車両転換など複数の取り組みが組み合わされている。
2. スコープ3の考え方により、荷主企業は委託先の物流事業者の排出まで自社の環境責任として問われる。
3. 物流の環境・労働対応は、CSR・ESG経営の一部として、企業価値に直結する経営課題になっている。

## 一問一答

**Q1.** 自社が購入した電力・熱の使用に伴うCO2排出はどのスコープに該当するか。
①スコープ1　②スコープ2　③スコープ3

> 解答：②

**Q2.** 委託した輸送事業者の排出するCO2は、荷主企業にとってどのスコープに該当するか。
①スコープ1　②スコープ2　③スコープ3

> 解答：③

**Q3.** 次の記述の正誤を答えよ。「荷主企業は、自社が直接トラックを保有していなければ、委託先の輸送によるCO2排出について責任を問われることはない」

> 解答：誤。スコープ3の考え方により、委託先の排出も自社の環境責任として問われるようになっている。

**Q4.** ESG経営における「S（社会）」の観点に該当する物流の取り組みはどれか。
①ドライバーの労働環境改善　②モーダルシフトによるCO2削減　③委託先の労務コンプライアンス管理

> 解答：①
