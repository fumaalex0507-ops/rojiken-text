# 03. 物流を支える人・労働・環境問題

## 「送料無料」の裏側で起きていること

ネット通販で「送料無料」の表示を見ると、まるで配送がタダであるかのように感じます。しかし実際には、誰かがトラックを運転し、荷物を積み降ろしし、その分の人件費や燃料費が発生しています。この章では、物流を支える「人」と、そこから生まれる社会問題について学びます。

## 深刻化するドライバー不足

日本の物流業界が抱える最大の課題の一つが、トラックドライバーの人手不足です。背景には次のような要因があります。

- 高齢化：トラックドライバーの平均年齢は全産業平均より高く、若年層の入職が少ない
- 労働環境：長時間労働・拘束時間の長さが敬遠されやすい
- 荷待ち時間：荷主側の都合で、トラックが荷卸し・積み込みの順番を待つ「荷待ち」が発生しやすい

これらが重なり、ドライバーという職業の魅力低下→人手不足→既存ドライバーへの負荷増加という悪循環が生まれています。

## 「2024年問題」とは何か

「2024年問題」は、働き方改革関連法によってトラックドライバーの時間外労働に上限規制（年960時間）が適用されたことで、物流業界の輸送能力が不足する問題を指します。

規制自体は労働環境改善のために必要なものですが、荷物の量が変わらないままドライバーの労働時間だけが制限されると、単純計算で「運べる荷物の量」が減ってしまいます。業界全体では、次のような対応が進められています。

| 対応の方向性 | 具体例 |
|---|---|
| モーダルシフト | トラック輸送の一部を、鉄道・船舶など大量輸送が可能な手段に切り替える |
| 共同配送 | 複数の荷主・企業が配送を共同化し、積載率を上げる |
| 荷待ち・荷役時間の削減 | 予約システムの導入、パレット化による積み降ろしの効率化 |
| 商慣行の見直し | 再配達の削減、リードタイムの見直し |

## モーダルシフトが必然である理由

モーダルシフトとは、トラック輸送の一部を鉄道や船舶に切り替えることです。なぜこれが必要とされるのか、理由は3つに整理できます。

1. **労働力の観点**：鉄道や船舶は、トラックに比べて少ない人数で大量の貨物を運べる
2. **環境の観点**：CO2排出量が、トラックに比べて鉄道・船舶は大幅に少ない
3. **安定性の観点**：長距離輸送において、渋滞や天候の影響を受けにくい

一方で、鉄道駅や港湾までの末端区間ではトラックが必要になるなど、モーダルシフトにも限界があります。実務では、輸送距離や荷物の特性に応じて輸送手段を組み合わせる「複合一貫輸送」という考え方が重要になります。

## 実務でどう使われているか

ある食品メーカーが、関東から関西への定期輸送をすべてトラックに頼っていたとします。ドライバー不足で輸送が不安定になったことをきっかけに、幹線区間を鉄道コンテナ輸送に切り替え、鉄道駅から工場・物流センターまでの近距離だけをトラックが担当する体制に変更しました。

この結果、長距離ドライバーへの依存が減り、CO2排出量も削減されるという、労働問題と環境問題の両方に効果がある取り組みになります。

## 3行まとめ

1. 物流はドライバーの人手不足という構造的な問題を抱えている。
2. 「2024年問題」は、時間外労働の上限規制により輸送能力が不足する問題である。
3. モーダルシフトや共同配送は、労働力不足と環境負荷という2つの課題に同時に対応する取り組みである。

## 一問一答

**Q1.** 「2024年問題」の直接の原因となった規制は何か。
①最低賃金の引き上げ　②トラックドライバーの時間外労働の上限規制　③消費税率の引き上げ

> 解答：②　働き方改革関連法による時間外労働の上限規制（年960時間）。

**Q2.** モーダルシフトの説明として正しいものはどれか。
①輸送をすべて自動運転に切り替えること　②トラック輸送の一部を鉄道・船舶などに切り替えること　③配送先を変更すること

> 解答：②

**Q3.** 次の記述の正誤を答えよ。「モーダルシフトを行えば、トラック輸送は一切不要になる」

> 解答：誤。鉄道駅や港湾までの末端区間ではトラックが必要であり、輸送手段を組み合わせる複合一貫輸送が重要になる。

**Q4.** 「荷待ち時間」の説明として最も適切なものはどれか。
①ドライバーが休憩のために停車している時間　②荷主側の都合で積み込み・荷卸しの順番を待つ時間　③渋滞により走行できない時間

> 解答：②
