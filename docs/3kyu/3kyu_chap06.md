# 06. 荷役とマテリアルハンドリング（MH）

## 「運ぶ」以外にも仕事がある

トラックが倉庫に到着してから、商品が棚に並ぶまでの間には、「積む」「降ろす」「移動する」「仕分ける」「並べる」といった、輸送そのものではない多くの作業があります。これらをまとめて「荷役（にやく）」と呼びます。この章では、荷役とその効率化技術であるマテリアルハンドリング（MH）を学びます。

## 荷役とは何か

荷役とは、輸送・保管に付随して発生する、モノの積み降ろし・移動・仕分けなどの作業全般を指します。代表的な荷役作業には、次のようなものがあります。

- 積み込み・積み降ろし（トラックへの積載・荷卸し）
- 運搬（倉庫内でのモノの移動）
- 積み付け（パレットやコンテナへの積み上げ）
- ピッキング（注文に応じて商品を取り出す作業）
- 仕分け（配送先別・商品別に荷物を分ける作業）

物流の6大機能の中で、荷役は「輸送」と「保管」の間をつなぐ役割を果たしています。輸送だけ、保管だけが効率化されても、その間の荷役に時間がかかれば、全体の効率は上がりません。

## 荷役の5大原則

荷役を効率化する上で押さえておくべき基本的な考え方として、次の5つの原則が知られています。

| 原則 | 内容 |
|---|---|
| 活性化の原則 | モノが手を加えなくても次に動かせる状態（活性）にしておく |
| 単純化の原則 | 作業の手順や動きをできるだけ単純にする |
| 数量減少の原則 | 荷役の回数・取扱量そのものを減らす |
| 移動の抑制の原則 | 不要な運搬・移動距離を減らす |
| 総合の原則 | 個別の作業ではなく、工程全体を通して最適化する |

これらの原則に共通するのは、「荷役は付加価値を生まない作業だからこそ、できる限り減らし、効率化すべきである」という発想です。

## マテリアルハンドリング（MH）とは

マテリアルハンドリング（MH）とは、荷役作業を機械化・自動化することで、効率化・省人化を図る技術や機器の総称です。代表的なMH機器には、次のようなものがあります。

- フォークリフト：パレットに積まれた荷物を持ち上げて運ぶ
- コンベア：荷物を連続的に移動させる搬送設備
- 自動倉庫（AS/RS）：ラックへの入出庫をコンピュータ制御で自動化する設備
- AGV（無人搬送車）：あらかじめ決められたルートを自動で走行し、荷物を運ぶ

近年は人手不足を背景に、ピッキングロボットや自動搬送ロボットなど、より高度なMH機器の導入が進んでいます。

## 実務でどう使われているか

ある物流センターで、商品の入荷から出荷までにかかる時間が長く、ボトルネックになっているとします。原因を調べると、パレットに積まれた荷物をいったん床に降ろしてから検品し、再度パレットに積み直すという、二度手間の作業が発生していました。

これは「活性化の原則」に反する動きです。パレットに載せたまま検品できるようにレイアウトや手順を見直すことで、荷役の回数そのものを減らし（数量減少の原則）、作業時間を大幅に短縮できます。

## 3行まとめ

1. 荷役は、輸送と保管をつなぐ「積む・降ろす・仕分ける」といった作業全般を指す。
2. 荷役の5大原則は、荷役をできる限り減らし、単純化・効率化するための考え方である。
3. マテリアルハンドリング（MH）は、荷役を機械化・自動化する技術であり、人手不足を背景に高度化が進んでいる。

## 一問一答

**Q1.** 荷役の5大原則に含まれないものはどれか。
①活性化の原則　②単純化の原則　③価格決定の原則

> 解答：③　5大原則は「活性化・単純化・数量減少・移動の抑制・総合」の原則。

**Q2.** あらかじめ決められたルートを自動で走行し荷物を運ぶ機器はどれか。
①フォークリフト　②AGV（無人搬送車）　③パレット

> 解答：②

**Q3.** 次の記述の正誤を答えよ。「荷役は物流の付加価値を生む中心的な工程であり、できる限り増やすべきである」

> 解答：誤。荷役は付加価値を生みにくい作業であり、5大原則にもとづきできる限り減らすべきとされる。

**Q4.** ラックへの入出庫をコンピュータ制御で自動化する設備はどれか。
①コンベア　②自動倉庫（AS/RS）　③トラックバース

> 解答：②
