# ロジスティクス検定 3級・2級 攻略ノート — 目次

> 通勤電車でスマホを片手に、無理なく合格レベルの理解に到達するための参考書です。
> 用語の丸暗記ではなく「なぜそうなるのか」「現場でどう使うのか」を軸に、ストーリーとして読めるように構成しています。

対象試験：ビジネス・キャリア検定試験「ロジスティクス分野」（ロジスティクス管理／ロジスティクス・オペレーション　各3級・2級）

## この教材の設計方針

| 項目 | 方針 |
|---|---|
| 想定読者 | 物流未経験〜実務2〜3年目。3級から2級まで通しで学べる |
| 想定シーン | 通勤電車内でのスマホ縦読み（1駅〜1回の乗車で1節読み切れる分量） |

| 章末 | 各章末に「3行まとめ」＋「一問一答（3〜5問）」を設置し、復習しやすくする |

## ディレクトリ構成

このリポジトリは VitePress で静的サイト化し、GitHub Pages（`https://fumaalex0507-ops.github.io/rojiken-text/`）で公開します。原稿は Markdown のまま、`docs/` 以下に配置します。

```
rojiken-text/
├── package.json                  ← VitePressの依存関係・ビルドスクリプト
├── .github/workflows/deploy.yml  ← push時に自動ビルド＆GitHub Pagesへデプロイ
└── docs/                         ← サイトのソース（VitePressの docsDir）
    ├── .vitepress/
    │   └── config.mts            ← ナビ・サイドバー・検索などのサイト設定
    ├── public/                   ← アイコン・manifestなど静的アセット
    ├── index.md                  ← 全体目次・進捗管理（このファイル）
    ├── 3kyu/
    │   └── 3kyu_chap01.md 〜 3kyu_chap16.md
    └── 2kyu/
        └── 2kyu_chap01.md 〜 2kyu_chap14.md
```

- 原稿執筆の対象は引き続き `docs/3kyu/*.md` `docs/2kyu/*.md` のMarkdownファイルのみです。サイトのナビゲーションやサイドバーは `.vitepress/config.mts` が自動生成するため、章ファイルを追加するたびに設定を書き換える必要はありません（未執筆の章は自動的にサイドバーから除外されます）。
- 3級・2級それぞれで「ロジスティクス管理」と「ロジスティクス・オペレーション」の2科目を扱いますが、ファイルは科目で分けず、学習の自然な流れ（概念→現場オペレーション→管理・データ）に沿って一本の連続したストーリーとして章立てします。
- どちらの科目の出題範囲に対応する内容かは、下記の目次テーブルの「対応科目」列に明記します。実際の受験科目（管理／オペレーション）ごとに読む章を選びたい場合も、この列を目印にできます。
- 章番号はスマホでの検索性を優先し、`3kyu_chap01.md` のように2桁ゼロ埋めの連番で統一します。
- iPhoneでは公開後のURLをSafariで開き、共有メニューから「ホーム画面に追加」するとアイコン付きでアプリのように起動できます。
- 用語集（`common/glossary.md`）は各章から `[[用語名]]` 的にリンクせず、章内で都度簡潔に解説し、glossaryは補助的な逆引き用とします。

## 学習チェック機能について

各章の末尾には「この章の理解度チェックリスト」を用意し、Markdownのタスクリスト（`- [ ]`）形式で自己採点できるようにしています。GitHub上ではそのままチェックを付けられます。

サイト（VitePress）上で、読者ごとにチェック状態を記憶し、全体の学習進捗（章別・項目別の達成率）をダッシュボードのように可視化する機能は今後の拡張候補です（ブラウザのlocalStorageなどを使った実装を想定）。実装は後回しにしますが、要望として記録しておきます。

## 各章の標準フォーマット（執筆時のテンプレート）

1. **導入（つかみ）**：現場や日常のたとえ話から入り、「なぜこの章を学ぶ必要があるのか」を1〜2段落で説明
2. **本質の解説**：定義→背景・理由→具体例の順で、短い段落と箇条書きを交互に使用
3. **比較表**：紛らわしい用語・方式は必ず表で対比（例：発注点方式 vs 定期発注方式）
4. **実務での使われ方**：現場での具体的シーン（1〜2例）
5. **3行まとめ**：章の要点を3行に凝縮
6. **一問一答（3〜5問）**：○×または穴埋め形式、解答は折りたたまず章末に明記
